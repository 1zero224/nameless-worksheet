## 1. 目标与退出条件

阶段 3 在已完成的表格协作与精修 UI 之上，打通“看分工 → 直接拿文件/网盘链接 → 登记新版本 → 查历史版本”的完整资源与网盘入口闭环（阶段 4 再叠加 Cloudflare R2 文件直传与签名下载）：

退出条件（全部满足才算完成，逐条对应第 10 节验收清单）：

1. **四级统一资源挂载（A01）**：支持在**通用文档（`/docs`）**、**作品大标题横幅**、**任务行**、**具体工序格**四个层级挂载资源；打开归属作品的任意分段任务详情侧栏时，顶部自动透出所属作品共用资源。
2. **直通取用与零分类负担**：全站不设僵硬的“资源分类”或“分组”下拉；工作表工序格角标点击弹出轻量快速取用浮层（一键打开链接、复制提取码、复制完整分享信息、快捷新增），作品横幅无提取码单入口胶囊可一键直跳、其余弹同款浮层，看板与「我的任务」卡片通过 `TaskResourcesPopover` 直接取用作品共用/本列工序/任务资源。
3. **版本历史与同版本多入口（A03）**：一步表单支持粘贴整段网盘分享文本自动解析服务商、URL 与提取码并生成 `资源 + v1 + 入口`；同一版本可挂多个互不影响的网盘入口（不升版本号）；内容更新时可登记新版本（v2、v3…）并保留全部旧版本历史；允许 0 入口版本（显示「待补充入口」）。
4. **生命周期保护与修改记录恢复**：延续 [ADR-0004](adr/0004-change-log-replaces-recycle-bin.md)，资源、版本与入口均采用软删除 + Toast 撤销 + 修改记录一键恢复（无独立回收站页）；删最新版前明确提示并自动回退显示剩余最高版本；删工序列自动把该列工序资源降级为任务级（保留原名并记入修改记录）；有共用资源的空作品横幅保持可见，解散分组时弹出确认并默认保留横幅与共用资源（可选一并软删）；支持改名与项目内跨挂载点移动（不升版本号）。
5. **通用文档与融合检索**：单行顶栏「任务看板」右侧新增「通用文档」标签入口（`/docs`，全体已登录用户可协作维护，含本页修改记录抽屉）；现有融合检索下拉（`KeywordSearchInput` + `GET /api/search`）支持检索资源名称并单独分区展示命中的通用文档，严格排除提取码与 URL。
6. **实时同步与零敏感泄漏（A07 / A17 / A21）**：资源、版本与入口增删改通过现有 `worksheet` 与 `project` 范围在 1 秒内实时同步给他人（事件仅携带 ID 与动作类型，**零提取码、零 URL**）；跨项目隔离测试覆盖全部新增带 ID 接口；外链仅放行 `http://` 与 `https://` 且新窗口隔离来源页打开。
7. **多端可用与交付**：桌面端（1440×900）与手机窄屏（390×844）下四级挂载、取用浮层、通用文档页与详情侧栏均正常可用且无横向溢出；CI 全绿并部署至香港 VPS 验证通过。

## 4. 数据模型与迁移

主键一律 `uuid`（`uuidv7()`），时间一律 `timestamptz`。所有表均含 `project_id`（外键 `projects.id`），数据访问层查询函数一律以 `projectId` 为第一必填参数。

### 4.1 新增枚举与表结构

#### 枚举

- `location_type`: `'cloud_link' | 'r2'`（阶段 3 仅写入 `'cloud_link'`，阶段 4 直接复用 `'r2'`）
- `cloud_provider`: `'baidu' | 'aliyun' | 'quark' | 'tianyi' | '115' | 'gdrive' | 'mega' | 'onedrive' | 'other'`

#### `artifacts`（资源）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | `uuid` 主键 | `uuidv7()` |
| `project_id` | `uuid` 非空，外键 `projects` | 权限边界 |
| `worksheet_id` | `uuid` 可空，外键 `worksheets` | 冗余用于按工作表批量查询摘要与实时范围定位；通用文档时为 `NULL` |
| `work_id` | `uuid` 可空，外键 `works` | 仅作品共用资源非空 |
| `task_id` | `uuid` 可空，外键 `tasks` | 任务级与工序格级资源非空 |
| `stage_column_id` | `uuid` 可空，外键 `column_configs` | 仅工序格级资源非空 |
| `name` | `text` 非空 | 1–120 字符（NFC + trim，不含控制字符） |
| `latest_version_id` | `uuid` 可空 | 指向当前最新未删版本（应用层在事务锁内维护，避免循环外键阻断建表） |
| `created_by` | `uuid` 非空，外键 `users` | 创建者 |
| `deleted_at` | `timestamptz` 可空 | 软删除时间 |
| `created_at` / `updated_at` | `timestamptz` | |

**数据库 `CHECK` 约束（`artifacts_scope_check`）**——在数据库层彻底杜绝非法归属组合：

```sql
CHECK (
  -- 1. 通用文档（项目级）
  (worksheet_id IS NULL AND work_id IS NULL AND task_id IS NULL AND stage_column_id IS NULL)
  OR
  -- 2. 作品共用资源
  (worksheet_id IS NOT NULL AND work_id IS NOT NULL AND task_id IS NULL AND stage_column_id IS NULL)
  OR
  -- 3. 任务级资源
  (worksheet_id IS NOT NULL AND work_id IS NULL AND task_id IS NOT NULL AND stage_column_id IS NULL)
  OR
  -- 4. 工序格级资源
  (worksheet_id IS NOT NULL AND work_id IS NULL AND task_id IS NOT NULL AND stage_column_id IS NOT NULL)
)
```

索引：
- `(project_id, updated_at DESC) WHERE worksheet_id IS NULL AND deleted_at IS NULL`（加速通用文档列表）
- `(project_id, worksheet_id) WHERE worksheet_id IS NOT NULL AND deleted_at IS NULL`（加速整表资源摘要加载）
- `(project_id, work_id) WHERE work_id IS NOT NULL AND deleted_at IS NULL`
- `(project_id, task_id) WHERE task_id IS NOT NULL AND deleted_at IS NULL`
- `(project_id, stage_column_id) WHERE stage_column_id IS NOT NULL AND deleted_at IS NULL`（加速删列降级）

- 新增索引：`(project_id, created_at DESC, id DESC) WHERE worksheet_id IS NULL AND artifact_id IS NOT NULL`（加速通用文档修改记录查询）

### 4.2 迁移

生成迁移文件 `apps/server/drizzle/0002_phase3_artifacts.sql`（通过 `pnpm db:generate` 生成后核对 `artifacts_scope_check` 约束与部分索引 SQL）。阶段 3 无需补种默认业务数据，旧项目迁移零停机平滑升级。

### 4.3 字段校验规则（`packages/shared/src/artifact.ts`）

| 字段 | 规则 |
|---|---|
| 资源名 `name` | 1–120 字符，NFC + trim，不含控制字符 |
| 版本说明 `note` | 0–200 字符，不含控制字符 |
| 入口 URL `url` | 必填合法 URL，协议严格仅限 `http:` 或 `https:`，长度 ≤ 2000 |
| 网盘服务商 `provider` | `baidu`（百度网盘）/ `aliyun`（阿里云盘）/ `quark`（夸克网盘）/ `tianyi`（天翼云盘）/ `115`（115网盘）/ `gdrive`（Google Drive）/ `mega`（MEGA）/ `onedrive`（OneDrive）/ `other`（其他） |
| 提取码 `extractCode` | 可空；非空时 trim 后 1–32 字符，不含空白与控制字符 |
| 是否文件夹 `isFolder` | 布尔值（表单必填选择：文件 / 文件夹） |
| 有效期 `expiresAt` | 可空；非空时匹配 `^\d{4}-\d{2}-\d{2}$` 且为合法日历日期 |
| 入口备注 `note` | 0–200 字符 |

### 4.4 核心不变量

1. **版本号单调递增且并发安全**：创建新版本时必须在 `withTx` 内 `SELECT ... FROM artifacts WHERE id = $1 FOR UPDATE` 锁住资源行，计算 `COALESCE(MAX(version_number), 0) + 1`（包含已软删版本），插入 `artifact_versions` 并更新 `artifacts.latest_version_id` 与 `updated_at`。两人并发创建新版本各自得到递增版本号，互不覆盖。
2. **`latest_version_id` 始终与未删版本一致**：
   - 新增版本成功 → 立即更新为新版本 ID；
   - 软删除版本后 → 在同一事务内重新查询该资源剩余未删版本中 `version_number` 最大者写回 `latest_version_id`（若全删则置 `NULL`）；
   - 从修改记录恢复版本后 → 同样重新计算未删版本中 `version_number` 最大者写回 `latest_version_id`（防止恢复旧版 v1 意外覆盖了新版 v2，或删掉唯一版本后恢复 v1 时能正确恢复为最新）。
3. **软删任务/工作表的级联隐藏与精确恢复**：
   - 删除任务时**不修改**名下 `artifacts.deleted_at`；所有读取接口与检索接口通过关联 `tasks.deleted_at IS NULL` 与 `worksheets.deleted_at IS NULL` 自动隐藏已删任务/工作表下的资源；
   - 因此恢复任务时，原本未被单独删除的资源与版本/入口关系自动完整还原，原本已被用户单独删除的资源不会被意外复活。
4. **删除工序列自动降级**：`DELETE /api/worksheets/:worksheetId/columns/:columnId`（当 `type === 'stage'`）在同一事务内执行：
   ```sql
   UPDATE artifacts
   SET stage_column_id = NULL, updated_at = NOW()
   WHERE project_id = $1 AND worksheet_id = $2 AND stage_column_id = $3 AND deleted_at IS NULL
   ```
   保留原资源名不变，并在该次 `column.deleted` 修改记录的 `summary` / `changes` 中注明已将 N 个工序资源转为任务级资源。
5. **归属一致性校验**：创建或移动资源时，服务端必须在事务内校验：
   - 作品共用：`work` 属于当前项目且所属 `worksheet` 未删，`worksheet_id` 由服务端自动取 `work.worksheetId`；
   - 任务级：`task` 属于当前项目、未删且所属 `worksheet` 未删，`worksheet_id` 由服务端自动取 `task.worksheetId`；
   - 工序格级：额外校验 `stageColumn` 属于该任务所在工作表、未删且 `type === 'stage'`；
   - **绝不信任客户端传来的 `worksheetId`**，一律由服务端按归属实体反查推导。

## 5. 核心业务规则

### 5.1 网盘分享文本解析与格式化（`packages/shared/src/share-parser.ts`）

纯前端/共用工具函数（零网络请求、100% 单元测试覆盖）：

1. **`detectCloudProvider(url: string): CloudProvider`**：
   - `pan.baidu.com` / `yun.baidu.com` → `baidu`
   - `alipan.com` / `aliyundrive.com` → `aliyun`
   - `pan.quark.cn` → `quark`
   - `cloud.189.cn` → `tianyi`
   - `115.com` / `115cdn.com` / `anxia.com` → `115`
   - `drive.google.com` / `docs.google.com` → `gdrive`
   - `mega.nz` / `mega.co.nz` → `mega`
   - `1drv.ms` / `onedrive.live.com` / `sharepoint.com` → `onedrive`
   - 其他任意合法 `http:` / `https:` 域名 → `other`（识别失败绝不拒绝）
2. **`parseShareText(raw: string)`**：
   - 从整段 QQ 群/网盘分享文本中提取首个合法 `https?://` URL（自动剔除末尾中文标点、括号、引号）；
   - 识别常见提取码写法：`提取码[:：]?\s*([A-Za-z0-9]{4,12})`、`访问码[:：]?\s*([A-Za-z0-9]{4,12})`、`密码[:：]?\s*([A-Za-z0-9]{4,12})`、`pwd=([A-Za-z0-9]{4,12})`（含 URL query `?pwd=xxxx`）；
   - 同步返回 `{ url, provider, extractCode, suggestedName? }`，供表单回填并由用户确认或手改。
3. **`formatShareInfo(artifactName: string, versionNumber: number, loc)`**：
   - 生成便于发回 QQ 群的一键复制文本，例：
     ```text
     5th-BD 原片 (v1)
     百度网盘：https://pan.baidu.com/s/1xxxx
     提取码：ab12
     ```
     （无提取码时省略提取码行；有有效期时可附 `有效期至：YYYY-MM-DD`）。

### 5.2 作品横幅可见性与「解散分组」保护

1. **作品可见性**：修改 `GET /api/worksheets/:id` 中计算可见作品的逻辑——凡满足以下任一条件的 `works` 行均返回并渲染作品大标题横幅：
   - 至少有 1 条未删任务引用该 `workId`；**或**
   - 至少有 1 条未删作品共用资源挂载在该 `workId` 下。
2. **原子解散分组接口 `POST /api/worksheets/:worksheetId/works/:workId/ungroup`**：
   - 请求体：`{ deleteSharedArtifacts?: boolean }`（默认 `false`）。
   - 在 `withTx` 事务内：
     - 将该工作表下所有归属该 `workId` 的未删任务置 `work_id = NULL`、`revision + 1` 并记修改记录；
     - 若 `deleteSharedArtifacts === true`，将挂载在该 `workId` 下的全部未删作品共用资源软删除（`deleted_at = now`），并在修改记录写入 `artifact.deleted` 条目支持一键恢复；
     - 广播 `worksheet` 范围的 `work.ungrouped`（客户端触发整表刷新）与 `project` 范围的 `board.task_changed`。
   - 前端点击「解散分组」时：
     - 若该作品无共用资源：沿用现有确认框直接调用 `ungroup`；
     - 若该作品仍有 `N > 0` 个共用资源：弹窗显式告知“该作品下还有 N 个共用资源”，默认仅移出任务并保留作品横幅与共用资源，附带可选复选框 **「同时删除这 N 个共用资源（可在修改记录中恢复）」**。

### 5.3 修改记录与一键恢复（延续 ADR-0004）

在 `withTx` 同事务写入 `change_logs`，**严禁在 `summary` 或 `changes` 中写入 `extractCode`**：

| `action` | 归属（`worksheetId` / `taskId` / `artifactId`） | `changes` 载荷（零提取码） | 是否支持恢复 |
|---|---|---|---|
| `artifact.created` | 对应表/任务/资源（通用文档时 `worksheetId = null`） | `{ artifactId, name, scopeKind, versionNumber }` | — |
| `artifact.updated` | 改名或移动归属（移动跨表时在目标表记记录） | `{ artifactId, name, diffs: [{ field, label, from, to }] }` | — |
| `artifact.deleted` | 删除资源 | `{ artifactId, name, scopeKind, latestVersionNumber }` | ✓（`POST /api/artifacts/:id/restore`） |
| `artifact.restored` | 恢复资源 | `{ artifactId, name }` | — |
| `artifact_version.created` | 登记新版本 | `{ artifactId, versionId, name, versionNumber, note }` | — |
| `artifact_version.deleted` | 软删版本 | `{ artifactId, versionId, name, versionNumber }` | ✓（`POST /api/artifact-versions/:versionId/restore`） |
| `artifact_version.restored` | 恢复版本 | `{ artifactId, versionId, name, versionNumber }` | — |
| `location.created` / `location.updated` / `location.deleted` / `location.restored` | 增改删恢复入口 | `{ artifactId, versionId, locationId, name, versionNumber, provider, isFolder, hasExtractCode }`（**绝不存 `extractCode` 原文，也不存完整敏感 URL**） | 删除时通过 Toast 撤销与 `POST /api/resource-locations/:id/restore` |

> **恢复前置检查**：恢复资源时若所属工作表或任务已被删除，返回 `409 CONFLICT` 并提示“所属任务/工作表已删除，请先恢复它”；若所属工序列已被删除，恢复该资源时自动降级为任务级（`stage_column_id = NULL`）并提示用户；恢复版本时若所属资源已删返回 `409 CONFLICT`。

### 5.4 安全与防泄漏红线

1. **提取码四不进**：
   - 不进 Fastify / Pino 日志（请求日志不打印 body，错误详情不回显 `extractCode`）；
   - 不进 `realtime_events.payload`；
   - 不进 `change_logs.summary` 与 `change_logs.changes`；
   - 不进 `GET /api/search` 匹配范围与返回值。
2. **协议白名单**：服务端 Zod 与前端渲染双重校验 URL 仅允许 `http:` / `https:`，拒绝 `javascript:`、`data:`、`file:` 等伪协议；所有外链渲染带 `target="_blank" rel="noopener noreferrer"`。
3. **跨项目隔离**：所有带 `:id` / `:artifactId` / `:versionId` / `:workId` / `:taskId` 的读写接口均按 `auth.projectId` 过滤，跨项目访问一律返回 `404 NOT_FOUND`。

## 6. 实时通道扩展

沿用阶段 1–2 的 `RealtimeHub`、`withTx` 咨询锁、游标补发与 `X-Connection-Id` 发起者去重，**不新增 `task` 订阅类型**，仅复用现有的 `worksheet` 与 `project` 两个订阅范围。

### 新增实时事件 `artifact.changed`

```ts
export interface ArtifactChangedPayload {
  scopeKind: 'doc' | 'work' | 'task' | 'stage';
  action:
    | 'artifact.created'
    | 'artifact.updated'
    | 'artifact.moved'
    | 'artifact.deleted'
    | 'artifact.restored'
    | 'version.created'
    | 'version.deleted'
    | 'version.restored'
    | 'location.created'
    | 'location.updated'
    | 'location.deleted'
    | 'location.restored';
  artifactId: string;
  worksheetId: string | null;
  workId: string | null;
  taskId: string | null;
  stageColumnId: string | null;
}
```

> 载荷**严格只含 ID 与枚举动作**，绝不携带资源名以外的敏感字段，更绝不携带 `url` 或 `extractCode`。

广播规则：
- **通用文档变更**：向 `project:{projectId}` 广播 `artifact.changed`（`scopeKind: 'doc'`）→ 驱动 `/docs` 页面实时刷新。
- **作品 / 任务 / 工序资源变更**：
  - 向 `worksheet:{worksheetId}` 广播 `artifact.changed` → 驱动工作表横幅胶囊、工序格角标、文件列计数以及已打开的 `TaskDetailDrawer` / 快速取用浮层刷新；
  - 同时向 `project:{projectId}` 广播 `board.task_changed`（`action: 'artifact.changed'`）→ 驱动首页看板与「我的任务」资源计数与已打开的 `TaskResourcesPopover` 防抖刷新（150ms）；
  - 跨工作表移动资源时，同时向原 `worksheet` 与目标 `worksheet` 各广播一次 `artifact.changed`。

   - **有提取码 / 多入口 / 0 入口**的胶囊：点击锚定弹出 `ArtifactQuickPopover`，支持一键打开链接、复制提取码、复制完整分享信息、登记新版本或补充入口；
   - 最右侧 `+ 附件` 按钮点击打开该作品的共用资源管理浮层（查看全部共用资源并一键新建）；
   - 横幅菜单「解散分组」接入保护确认框（有共用资源时提示数量、默认保留横幅与共用资源、可选勾选同时软删）。
2. **工序格附件角标（`stageCellRenderer.ts` + `ArtifactQuickPopover`）**：
   - 当某工序格存在 ≥1 个未删资源时，`getCellContent` 为 `IStageCell.data.attachment` 填入最近更新资源的最新版摘要（如 `label: 'v2'` 或多资源 `'v2 +2'`，`kind: 'link'`）；
   - 点击角标热区（`onAttachmentClick`）**不打开大侧栏**，而是在该单元格旁弹出 `ArtifactQuickPopover`：列出本工序格全部资源的最新版本与一键取用按钮，底部提供「+ 添加资源」「+ 登记新版本」与「在详情侧栏中管理全部历史」；
   - 点击工序格其他区域仍打开现有的 `StageCellEditor` 浮层（并在底部接通本工序资源快捷入口，替换占位）；
   - 在工序格内点击「+ 添加资源」时，表单自动预填资源名为当前工序名（如 `翻译`），用户可直接回车保存或按需修改。
3. **固定「文件」列**：
   - 显示本任务汇总资源总数（任务级 + 全部工序格，如 `3 个资源`，0 个时显示轻量 `+`）；点击打开 `TaskDetailDrawer` 并自动滚动聚焦至文件区；仍可在 `FieldVisibilityPopover` 中按需隐藏。

### 8.4 任务详情侧栏（`TaskDetailDrawer.tsx`）与看板快捷资源弹层（`TaskResourcesPopover.tsx`）

1. **`TaskDetailDrawer`**：
   - 顶部 **所属作品共用资源** 区块（仅当任务归属作品时出现）：替换原阶段 3 占位，展示整部作品共用资源的最新版本、一键取用按钮与「+ 添加作品共用资源」；

     - **各工序交付**（按本工作表工序列顺序，每道工序显示其资源列表 +「+ 添加」快捷按钮）；
     - **任务其他资源**（直接挂在任务行上的资源 +「+ 添加」按钮）；
   - 全部资源卡片复用 `ArtifactCardList`：支持多入口、复制提取码、复制分享信息、登记新版本、展开历史版本、改名/移动归属与软删（带 Toast 撤销）。
2. **看板与「我的任务」卡片（`TaskResourcesPopover.tsx`）**：
