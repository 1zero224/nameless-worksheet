# 工作表多维表格化改版：实验设计文档

状态：实验分支设计稿（供新分支快速落地与效果验证） · 日期：2026-11-25  
术语依据：[GLOSSARY.md](../GLOSSARY.md) · 现行功能契约：[feature-map.md](feature-map.md)

## 1. 实验目标与边界

### 1.1 要解决的偏移问题

当前阶段 2 已交付的工作表在功能、实时协同与权限上完整可用，但视觉与交互形态偏向“企业管理后台（灰底卡片 + 固定操作列 + 弹窗配结构）”，与最初设想的**“像飞书多维表格一样紧凑直观、以工作表平面为中心、配合看板流转、后续单格直通最新附件”**存在明显体感差距。

本实验分支的目标：**在不推翻后端、数据库与实时协同的前提下，纯前端把工作表与导航壳层拉齐到“飞书多维表格”形态，并把工序格的视觉与交互为阶段 3“工序格直挂附件”铺平。**

### 1.2 硬性边界（保证新分支可快速试验、低成本回退）

- **零数据库迁移、零后端接口破坏**：全部复用阶段 1–2 现有 REST API 与 WebSocket 实时事件，不改 PostgreSQL schema。
- **不引入新网格依赖**：继续基于当前 React + TanStack Table + Radix UI 实现（保留完整的中文 IME 保护、字段级冲突条、在线状态焦点框、移动端适配）；待本实验验证视觉与键盘导航手感后，再判断是否需要另测 Canvas 网格（如 Glide Data Grid）。
- **保持核心业务规则不变**：实时协同、在线状态、中文输入法防打断、字段级冲突提示、已发布折叠、跨表看板四列并行流转与抢认领规则完全沿用。
- **阶段 3 附件能力仅做槽位与模型衔接说明**：本实验分支不伪造持久化的假文件数据，只把工序格布局和右侧结构留好，避免污染数据库。

## 2. 现状与目标形态对照

| 维度 | 现状（阶段 2） | 实验目标（飞书多维表格形态） |
|---|---|---|

| **顶部操作区** | 大标题一行 + 独立圆角筛选卡片一行 + 绿色已发布大卡片一行 | **双层极简顶栏**：上层表名/在线状态/修改记录（44px），下层单行紧凑工具栏（36px） |
| **最左侧行操作** | 固定 72px 宽「操作」列，每行常驻 4 个按钮 | **40px 极窄行号列**：默认显示 `1, 2, 3…`，仅悬停/选中时显示拖拽手柄与展开详情按钮 |
| **列管理与新增** | 点击右上角「列设置」打开大型居中弹窗 | **表头原地操作**：最右直接挂 `+` 列头原地加列；点击任意列头弹出菜单改名/调序/设看板映射/隐藏/删除 |

## 3. 全局壳层与左侧导航改版

涉及文件：`apps/web/src/app/AppShell.tsx`、`apps/web/src/pages/WorksheetsPage.tsx`（复用其弹窗逻辑拆成公共组件）。

### 3.1 全屏贴边画布

- 当路由为 `/worksheets/:id` 或 `/`（首页看板）时：
  - `<main>` 去掉 `p-4 sm:p-6`，改为 `flex h-screen flex-col overflow-hidden bg-white p-0`（窄屏扣除顶部 48px 栏高 `h-[calc(100dvh-48px)]`）；
  - 其他配置/列表页（`/my-tasks`、`/search`、`/settings`、`/admin/*`）保持现有舒适留白布局不变。

### 3.2 左侧导航收窄与原地管理工作表

- 桌面端左侧栏宽度从 `w-60`（240px）收窄至 `w-52`（208px），底色 `bg-slate-50/70`，右侧细分割线 `border-r border-slate-200/80`，支持顶部按钮**一键折叠/展开左侧栏**（折叠后给宽表腾出完整屏幕宽度，偏好存 `localStorage`）。
- 导航顺序调整为以“看板 + 工作表”为主轴：
  1. 顶区：`任务看板`（`/`）、`我的任务`（`/my-tasks`）、`资源检索`（`/search`）、`参考资料`（`/references`）
  2. 主区：**工作表列表**
     - 分组标题右侧的 `+` 直接弹出轻量「新建工作表」弹窗（名称、颜色、模板），**不再跳走页面**；
     - 列表中每个工作表项悬停显示 `⋯` 菜单（重命名/改色、删除二次确认），支持直接拖拽排序（复用 `PUT /api/worksheets/reorder`）；
     - 选中态改为飞书风浅色高亮条（如 `bg-sky-50 text-sky-900 font-medium`），不再使用厚重的纯黑块 `bg-slate-900`。
  3. 底区：`个人设置` 与管理员入口收拢在左下角紧凑区域。

## 4. 工作表核心画布改版（飞书多维表格形态）

涉及文件：`apps/web/src/pages/WorksheetDetailPage.tsx`、新增轻量列头菜单组件与表头 `+` 新增列组件。

### 4.1 整体纵向结构（占满 100vh，内部滚动）

```text
┌───────────────────────────────────────────────────────────────────────────┐
│ ● 长视频全熟  (未发布 12 · 已发布 4)       [在线: 小林 小陈]  [修改记录]   │ ← 顶栏 44px
├───────────────────────────────────────────────────────────────────────────┤
│ 视图筛选: [全部|我的|未开始|进行中]  [搜关键词] [作品▾] [负责人▾] [排序▾] [字段显隐▾] │ ← 工具栏 38px
├───────────────────────────────────────────────────────────────────────────┤
│ ▸ 已发布（4 条）                                                          │ ← 紧凑折叠条 30px（仅存在已发布任务时显示）
├────┬──────────────────┬────────┬────────────┬────────────┬────────────┬───┤
│ #  │ 标题（冻结）      │ 作品   │ 时轴 ▾     │ 翻译 ▾     │ 校对 ▾     │ + │ ← 表头 34px（sticky top）
├────┼──────────────────┼────────┼────────────┼────────────┼────────────┼───┤
│ 1  │ 武道馆 live P1    │ 武道馆 │ 小林  [v2] │ 小张       │ 待认领     │   │ ← 行高 36px，细线网格
│ 2  │ 武道馆 live P2    │ 武道馆 │ 小林  [v1] │ 小陈  [v1] │ 待认领     │   │
├────┴──────────────────┴────────┴────────────┴────────────┴────────────┴───┤
│ + 新建任务（点击输入标题，回车连续添加）                                    │ ← 贴合表格底行 36px
└───────────────────────────────────────────────────────────────────────────┘
```

### 4.2 极窄行号列（替换原 72px 操作列）

- 列宽固定 **`40px`**，粘性冻结在 `left: 0`（`z-30`），标题列紧接在 `left: 40px`。
- 默认态居中显示柔和行号（`1`、`2`、`3`…，`text-xs text-slate-400 tabular-nums`）。
- 行悬停（`group-hover`）或当前行内有单元格选中时，行号切换为紧凑控件：
  - 左侧微距拖拽手柄（仅默认顺序时启用拖拽）；
  - 右侧「展开详情」小图标（点击打开右侧 `TaskDetailDrawer`）；
- 右键整行（或点击行号旁 `⋯`）提供轻量上下文菜单：**展开任务详情 / 在下方插入一行 / 删除任务**（删除保留现有 Toast 一键撤销）。

### 4.3 表头原地交互（去掉对重型弹窗的强依赖）

1. **最右侧 `+` 列头**（固定 `w-10`）：
   - 点击弹出轻量 `Popover`（非整屏居中 Modal）：输入列名、选择类型（`工序 / 文本 / 日期 / 链接`，默认 `工序`）、若为工序可选对应看板列（默认按同名自动匹配），回车即调用 `POST /api/worksheets/:id/columns` 新增列。
2. **每个数据列头点击弹出「列菜单 Popover」**：
   - **自定义列 / 工序列**：
     - 顶部直接可编辑列名输入框（回车/失焦调用 `PATCH /api/worksheets/:id/columns/:columnId`）；
     - 若为工序列：内联下拉选择「对应看板列（不上看板 / 时轴 / 翻译 / …）」；
     - `向左移动` / `向右移动`（调用 `PUT /api/worksheets/:id/columns/reorder`）；
     - `隐藏此列`；
     - `删除此列`（二次确认）。
   - **固定系统列**（作品、分工说明、优先级、发布信息、文件）：
     - 支持一键 `隐藏此列`（调用 `PATCH /api/worksheets/:id` 更新 `systemColumns`）；标题列不可隐藏。
3. **工具栏「字段显隐」Popover**：
   - 保留一个轻量的列显隐与拖拽排序 Popover（复用现有 `ColumnManagerModal` 的逻辑并轻量化），用于找回已隐藏的列或批量拖拽排序列。
4. **列宽拖拽**：保留现有表头右缘 6px 隐形拖拽热区（悬停高亮天蓝细竖线 `bg-sky-500`），拖拽结束后落库同步。

### 4.4 网格线与行高密度

- 单元格边界统一改为柔和细线：`border-slate-200/80`，不再出现粗黑边框。
- 默认紧凑行高 **`36px`**（原 38px+ 内边距偏松）；所有单元格内部文字统一 `text-[13px]`，截断清晰，悬停可看完整 tooltip。
- 选中单元格采用飞书/多维表格经典的**天蓝色 2px 内描边**（`ring-2 ring-inset ring-sky-500`），与他人的彩色在线状态焦点框（`PeerOverlay`）在视觉上清晰区分。

### 4.5 键盘导航与快速录入

维护当前聚焦坐标 `selectedCell: { rowIndex, colIndex }`（基于当前可见行与可见列）：
- **非编辑态**：
  - `ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight`：在单元格之间移动选中框，并自动 `scrollIntoView({ block: 'nearest', inline: 'nearest' })`；
  - `Tab` / `Shift+Tab`：向右 / 向左移动（行尾自动折到下一行首）；
  - `Enter` 或 `F2`：
    - 文本/日期/链接格 → 进入编辑态；
    - 工序格 / 作品格 / 优先级格 / 发布信息格 → 直接打开对应 Popover；
  - `Escape`：清除选中态。
- **编辑态**：
  - 严格保留现有中文输入法保护（`isComposingRef` / `e.nativeEvent.isComposing`）；
  - 文本格 `Enter` 提交后自动将焦点下移一行（可选，像表格软件一样连续录多行）；`Esc` 取消还原。
- **底部 `+ 新建任务` 原地行**：
  - 视觉上作为表格最后一行贴合网格线，左格显示 `+`，标题格直接点击输入，回车提交后保持聚焦状态支持连续录入多条任务；若在筛选/已发布区域则按原逻辑处理。

## 5. 工序格重构与“单格直通附件”预留设计

涉及文件：`apps/web/src/components/worksheet/CellEditors.tsx`、`apps/web/src/components/ui/colors.ts`。

### 5.1 整格着色，一眼看懂流水线进度

将工序格从“白底 + 内部小胶囊”改为**整格柔和状态底色 + 左侧细色条（或状态圆点）**，扫一眼一整行就知道每条片段卡在哪个环节：

| 工序状态 | 单元格背景色 | 文字主色 | 备注/无负责人时表现 |
|---|---|---|---|
| `not_started`（未开始） | 透明 / 纯白（悬停 `bg-slate-50`） | 有负责人：`text-slate-700`；无负责人：`text-slate-400` 淡显 `待认领` | 状态圆点灰 |
| `in_progress`（进行中） | `bg-sky-50/90`（悬停 `bg-sky-100/70`） | `text-sky-900 font-medium` | 左侧 2px `bg-sky-500` 或蓝点 |
| `done`（已完成） | `bg-emerald-50/90`（悬停 `bg-emerald-100/70`） | `text-emerald-900 font-medium` | 左侧 2px `bg-emerald-500` 或绿勾 |
| `na`（不适用） | `bg-slate-100/80`（极淡斜纹可选） | `text-slate-400 line-through` 或 `—` | 视觉退后，不干扰视线 |

### 5.2 工序格内部布局（单格走完流程）

```text
┌──────────────────────────────┐
│ ● 小林          [⬇ v2]  💬  │  ← 整格浅绿底（已完成）
└──────────────────────────────┘
  ↑ 点击左侧/空白处：弹 Popover 改负责人、状态、备注、（阶段 3）上传新版/网盘/历史
                  ↑ 点击附件角标（阻止冒泡）：直接下载最新版或直跳网盘
```

- **左侧**：状态点/图标 + 负责人名字（单人直接显示 `小林`，多人显示 `小林, 小陈` 或 `小林 +2`）。
- **右侧**：
  - 若有备注，显示极小 `💬` 提示图标（悬停显示备注全文）；
  - **附件快捷角标槽位**（面向阶段 3）：
    - 当该工序格已有挂接文件/网盘时，展示紧凑小胶囊（如 `⬇ v2` 或 `🔗 网盘`），**点击角标直接触发下载最新 R2 版本或新标签打开网盘（`stopPropagation`，不弹出编辑浮层）**；
    - 本次实验分支（阶段 2 后端尚未接入文件）默认不渲染假角标，仅在工序格 Popover 底部预留「本工序附件（阶段 3 接入）」轻提示区，并在代码中保留 `StageAttachmentBadge` 槽位接口，方便阶段 3 无缝点亮。

### 5.3 与阶段 3 数据模型的无缝衔接说明（备忘）

等实验分支验证通过、进入阶段 3 开发文件与网盘时：
- 在 `artifacts` 表新增一个可空外键 `stage_column_id`（关联 `column_configs.id`，删除工序列时 `ON DELETE SET NULL` 退回任务通用文件，不丢文件）：
  - `stage_column_id != null`：属于该任务的某道具体工序 → 直接出现在对应**工序格右侧角标**及**工序格 Popover** 中（同时汇总展示在任务详情侧栏）；
  - `stage_column_id == null`：属于任务通用文件（如原片、参考资料、最终压制成品）→ 出现在「文件」列与任务详情侧栏。
- 这样既满足“在【时轴】格内直接下载最新空轴”，又保留了原片/压制成品等不属于单一工序的文件归属。

## 8. 验证与验收标准

### 8.1 必须保持不回退的现有能力与定位契约

- 所有 `data-testid` 核心契约继续保持：`sidebar-worksheets`、`worksheet-main-table`、`worksheet-table-scroll`、`presence-bar`、`published-section`、`cell-<taskId>-<columnKey>`、`peer-focus-badge`、`cell-conflict-bar`、`task-detail-drawer`。
- 中文输入法（IME）组字期间按 `Enter` 不提前提交、远端更新不覆盖编辑中草稿。
- 两人同开工作表时，实时更新、在线状态焦点框、同行不同字段互不覆盖、同格并发冲突浮条均正常工作。
- 窄屏 `390×844` 下 `scrollWidth <= innerWidth`，左侧抽屉可开关，宽表可在容器内横向滚动，页面整体不错位。

### 8.2 主观体验试玩检查点（供开分支实测评判）

1. 打开一张含 6+ 列、10+ 行任务的工作表，视觉第一眼是否明显像“飞书多维表格”而非“管理后台”？
2. 只用键盘（方向键 + `Enter` + 中文输入 + `Tab`）连续录 3 行任务并填写标题/分工说明，是否顺手？
3. 在表头点 `+` 加一列、点列头改名和隐藏列，是否不再需要到处找设置弹窗？
4. 扫一眼整张表的工序格颜色分布，是否不用读小字就能立刻看出哪几条片段已完成、哪几条进行中、哪几条缺人？
5. 在桌面 `1440×900` 与手机 `390×844` 上来回切换「任务看板」与各「工作表」，是否轻快、无割裂感？
