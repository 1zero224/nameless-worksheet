# 功能地图与端到端验收标尺（Feature Map）

本文从**用户视角**记录系统各页面的核心路径、稳定定位契约（语义角色 / `data-testid`）、快捷键、边界行为与完成判据，供两类场景直接复用：
1. 编写与维护 Playwright E2E 测试；
2. 编码代理真跑应用做浏览器冒烟检查时的评分标尺（Rubric）。

> 术语严格对齐 [GLOSSARY.md](../GLOSSARY.md)；随每个阶段交付与界面精修同步维护，不在本文堆积过时占位描述。

---

## 1. 全局壳层与通用不变量

| 维度 | 完成判据 |
|---|---|
| 认证守卫 | 未登录访问任意业务路由重定向至 `/login?next=<原路径>`（防开放重定向，仅允许单 `/` 开头）；会话被重置/改密/登出后，实时连接以 `4401` 断开且页面跳回 `/login`。 |
| 单行顶栏与导航实时性 | 顶部单行 44px 导航轨包含：`项目名` \| `任务看板`（`/`） \| （阶段 3：`通用文档` `/docs`） \| 可横向拖动排序的未删工作表标签（共享 `layoutId` 弹簧滑块、无标签色点、悬停 `⋯` 菜单原地重命名/删除） \| `+` 快速建表（`topbar-create-worksheet`） \| 页面右侧操作槽（在线状态/修改记录） \| 右上角用户头像菜单（`user-avatar-trigger`）；工作表增删改名拖序无需刷新实时同步；无「归档」与独立「回收站」入口（ADR-0004）。 |
| 角色可见性 | 普通用户头像菜单中看不到管理入口（`用户与邀请`、`存储`、`实时通道诊断`），直访 `/admin/*` 显示标题 `无权访问`；工作表结构、看板列配置与通用文档协作对所有已登录用户开放（ADR-0003）。 |
| 全站状态色系 | 看板卡片、左侧「我的任务」与工作表工序格统一采用原工作表语义底色：浅红 = 空缺（未开始且无负责人）、浅黄 = 进行中、纯白 = 已认领未开始、浅绿 = 已完成、浅灰 = 不适用；全站不渲染工作表标签颜色色点。 |
| 手机窄屏（390×844） | `document.documentElement.scrollWidth <= window.innerWidth`；首页「我的任务」收拢为顶部抽屉触发按钮（`mobile-my-tasks-trigger`）；看板列可横向滑动；工作表允许表格容器内横向滚动，点击行或详情图标进入全屏 `TaskDetailDrawer`。 |
| 零敏感泄漏 | 服务端 JSON 日志、修改记录、搜索索引与实时事件 payload 均不含密码、`nw_session=`、邀请令牌、重置令牌、提取码（阶段 3 起）与签名 URL（阶段 4 起）。 |

## 2. 阶段 1 页面（已交付）

| 路由 | 核心用户流程 | 关键定位契约 | 完成判据 |
|---|---|---|---|
| `/reset/:token` | 初始管理员或被重置用户设置新密码 → 跳转 `/login?reset=1` | 标题 `设置新密码`、输入 `新密码` / `确认新密码`、按钮 `保存新密码` | 成功后提示 `密码已设置，请使用新密码登录`，旧会话全部失效 |
| `/login` | 输入登录名（大小写不敏感）与密码登录 → 进入首页 `/` | 输入 `登录名` / `密码`、按钮 `登录` | 账号不存在与密码错误提示完全一致；连续失败触发锁定 |
| `/invite/:token` | 凭一次性/限次邀请链接注册 → 自动登录进入首页 | 输入 `登录名` / `显示名` / `密码` / `确认密码`、按钮 `完成注册` | 支持中文、日文假名与全角字符；用完/作废/过期均提示 `邀请链接无效或已过期，请联系管理员` |
| `/settings` | 修改显示名、修改密码 | 输入 `显示名`、按钮 `保存显示名` | 修改显示名后提示 `显示名已更新` 并实时同步给他人；改密保留当前会话、踢掉其他设备 |
| `/admin/users` | 管理员生成邀请链接、调整用户角色、生成重置链接 | 按钮 `生成邀请链接` / `生成重置链接` / `确认生成` / `我已保存`、`data-testid="one-time-link-input"`、`#invRole` | 一次性链接仅展示一次；不能降级最后一位管理员；重置立即踢目标用户下线 |
| `/admin/realtime` | 管理员测试实时通道连通、断线模拟与补发 | 按钮 `发送测试事件` / `模拟断线` / `恢复连接`、`data-testid="diag-cursor"`、`data-testid="diag-event-log"` | 甲发事件乙 1 秒内可见；断线后恢复按序补齐且无重复 |

## 3. 阶段 2 + Teable 级 UI 重构与精修（已交付）

| 路由 / 组件 | 核心用户流程 | 键盘 / IME / 交互契约 | 稳定定位与完成判据 |
|---|---|---|---|
| `/`（首页：任务看板 + 左侧我的任务竖栏） | 左侧可折叠「我的任务」竖栏（分「进行中」「待开始」一键开始/完成，窄屏为抽屉）；单行筛选工具栏含融合关键词跨表检索（`KeywordSearchInput`）、工作表/作品下拉、「仅看空缺」「仅看与我有关」与右上角「管理看板列」弹窗；右侧自适应弹性看板支持列竖向折叠、横向滚动与鼠标手拖滑动；列内与作品内按「空缺 → 进行中 → 已认领未开始」稳定排序；同列同作品 ≥2 条默认展开树形子卡（`├─ / └─`），单条用作品眉标，支持跨列悬停联动；点击整卡打开详情侧栏，点击举手「空缺」按钮原子抢认领，点击资源按钮打开 `TaskResourcesPopover` | 认领与改状态期间按钮禁用防连点；融合搜索框支持 220ms 防抖跨表检索（`global-search-dropdown`），点击结果直达 `/worksheets/:id?taskId=:taskId` | 初始 4 列（时轴/翻译/校对/嵌字）；并行进行中多列显示；未开始落首个未完成上看板适用工序列；`na` 跳过；已发布或上看板适用工序全完成离开看板；认领只填负责人保持 `not_started` 且 1 秒内同步他人；并发抢认领后到者收 409 Toast；「我的任务」绝不混入纯文本负责人或 `na` |
| `/worksheets` | 工作表总览（从右上角头像菜单进入）：新建工作表（名称 + 4 套模板，无颜色选择）、拖动排序、重命名、二次确认删表；项目级看板列增删改拖动排序 | 删工作表/删看板列均需确认弹窗 | 模板建表自动匹配同名看板列；删看板列后关联工序列自动置空（不上看板）且首页看板立即变化 |
| `/worksheets/:id` | 全屏贴边 Teable Canvas 表格（无冗余表内看板切换、已彻底移除「作品」列、「分工说明」列位于末列、已去掉作品任务行左侧彩色导轨线）；跨整行可折叠「作品大标题横幅」（`work-banner-<id>`，标题与进度右侧**靠左紧跟**作品共用资源胶囊、`+ 附件`、`+ 添加分段`、`更多`，共用资源胶囊共用单 `Popover` 动态锚点切换不闪退）与无作品任务平铺；顶部 `已发布（N 条）` 默认折叠条；紧贴最新行的原地新建行、`+ 新建作品`、拖动排序与跨作品拖拽、软删（`sonner` Toast 一键撤销）；工序格整格状态底色 + 负责人/状态右侧**直接展示工序备注** + 右侧附件角标热区 + 靠左对齐的锚定 Radix 编辑器/资源浮层；**右键单元格菜单**支持「查看单元格修改记录」（`context-menu-cell-history`），打开按该单元格过滤的修改记录抽屉并支持顶部「当前单元格 / 整条任务」切换（`cell-history-scope-bar`）；表头 `+` 原地加列、列头菜单、字段显隐与列宽拖动落库；顶栏右侧槽展示在线用户头像与「修改记录」抽屉入口；筛选栏集成融合关键词检索与本地排序 | 文本格：单击选中（`editing: false`），双击或 `Enter` 编辑（`editing: true`），`Enter`/失焦提交，`Esc` 取消；支持方向键/`Tab` 跨格导航；**中文 IME**：`compositionstart` 至 `compositionend` 期间按 `Enter` 不提交、远端更新不覆盖草稿；启用筛选或非默认排序时禁用行拖动 | 同行改不同字段互不覆盖；同格并发冲突贴附 `[保留我的]` / `[采用对方的]` 冲突条且不丢草稿；所有工序完成但未发布**不折叠**，仅已发布折叠；他人关闭页面后头像与 Canvas `collaborators` 焦点框自动消失；断线补发与超限 `resync` 后数据一致；带 `?taskId=` 跳转自动展开（若已发布或所在作品已折叠）、滚动高亮并打开侧栏 |
| 任务详情侧栏（`TaskDetailDrawer`） | 桌面端右侧滑出、手机端全屏抽屉；编辑标题/所属作品/优先级/分工说明/发布信息/自定义字段；**统一「工序与交付」区**（上白下微灰双段式工序卡片：上半部纯白区一站式编辑工序负责人 `Popover` 选择器、状态与带图标标签的备注，下半部微灰托盘区展示本工序交付资源，下方附「任务其他资源」）；展开本任务修改记录；归属作品的任务在**侧栏最底部**展示「所属作品共用资源」平铺列表；点「在工作表中定位」跳转 | `Esc` 关闭侧栏（非输入法组字且无内层弹层时） | 任意页面修改后其他页面 1 秒内实时同步 |

## 4. 阶段 3 契约（已交付：四级资源挂载、多网盘、版本历史与通用文档）

| 路由 / 触点 | 核心用户流程 | 关键交互与安全判据 |
|---|---|---|
| `/docs`（通用文档页） | 从单行顶栏「任务看板」右侧「通用文档」标签进入；平铺列表展示项目级公共资源，支持关键词过滤、一步创建（亮色归属标签 + 粘贴分享文本自动解析服务商/URL/提取码 + 仅留单个「备注」字段）、`···` 菜单「补充多网盘」、版本胶囊内嵌 `+`（悬浮/聚焦展开「更新」）登记新版本、仅当版本数 > 1 时显示历史展开按钮、改名/移动归属、软删（Toast 撤销）与本页修改记录抽屉一键恢复 | 全体已登录用户可维护；全站无全局「资源分类」或「分组」下拉；无入口验证状态开关；仅放行 `http://` 与 `https://` 外链且新窗口隔离打开；双端 1 秒内实时同步 |
| 工作表四级挂载触点 | 作品大标题横幅标题/进度右侧紧跟共用资源胶囊（无提取码单链接直跳、其余共用单 `Popover` 动态锚点弹出 `ArtifactQuickPopover`，连续切换不闪退；`+ 附件` 打开管理浮层）；工序格右侧角标热区点击弹出靠左对齐的 `ArtifactQuickPopover`；弹出新建/更新/多网盘弹窗前自动关闭背后资源浮层确保单窗口聚焦；新建资源顶部亮色标签展示「工作表 › 作品 › 任务 › 工序」（`artifact-scope-tags`），默认名称为「作品名-任务名-工序」；固定「文件」列展示本任务汇总资源数并点击直达详情侧栏 | 有共用资源的空作品刷新不消失；解散分组遇共用资源弹出确认并默认保留横幅与共用资源（可选勾选同时软删）；删工序列自动降级该列工序资源为任务级并保留原名、记入修改记录 |
| `ArtifactCardList` & `TaskResourcesPopover` | 紧凑平铺列表（去套娃边框），资源与下方网盘链接通过左侧 2px 树形竖线引导归属；单行网盘条将**网盘名直接作为外链**、**提取码胶囊直接作为复制按钮**（复制反馈 ✓）、紧邻右侧放置**分享按钮**，最右侧网盘 `···` 仅在悬浮/聚焦显现；看板与「我的任务」卡片点击 `card-resources-btn-<taskId>` 在紧凑弹层内直接取用作品共用/本列工序/任务资源 | 同版本多网盘互不影响（A03）；登记新版本立即成为最新并保留旧版历史；删最新版二次确认并自动回退至剩余最高版本；允许 0 链接版本（显示「待补充多网盘」） |
| 融合检索（`KeywordSearchInput`） | 顶部搜索框输入关键词同时匹配任务字段与资源名称（含作品/任务/工序资源），并在下拉中分区展示命中的通用文档，点击直达 `/docs?artifactId=<id>` | 检索结果与索引严格不包含提取码与 URL；跨项目数据零泄漏 |

## 5. 后续阶段预留契约（差分测试与专项验证）

- **阶段 4（R2 上传下载与预览）**：在阶段 3 的四级资源与版本模型之上接入 `blobs` / `upload_sessions` / Uppy 单次与分片断点续传、服务端完成校验、签名下载（中文文件名还原）与文件预览；覆盖指纹阶段进度与取消（A16）、幂等与并发版本属性测试、签名 URL 零日志/零事件泄漏扫描。
- **阶段 5（旧资料导入 — 差分测试 Oracle）**：以字幕组 23 张历史 Excel 工作表的小样 + 人工确认映射作为 Oracle，将“导入 → 系统结构化导出”与 Oracle 逐行差分比对，维护显式归一化白名单（全角空白/NFC 等）；同批数据重复导入 2 次数据库状态零漂移；群文件树导入直接复用阶段 3 的 0 入口版本（待补充入口）。
- **阶段 6（运维与备份恢复）**：备份恢复前后执行全库关键实体（工作表、任务、工序格、资源、版本、入口）差分快照一致性校验；管理员存储统计与物理清理页直接基于软删除状态与 R2 字节引用工作。
