# 功能地图与端到端验收标尺（Feature Map）

本文从**用户视角**记录系统各页面的核心路径、稳定定位契约（语义角色 / `data-testid`）、快捷键、边界行为与完成判据，供两类场景直接复用：
1. 编写与维护 Playwright E2E 测试；
2. 编码代理真跑应用做浏览器冒烟检查时的评分标尺（Rubric）。

> 术语严格对齐 [GLOSSARY.md](../GLOSSARY.md)；随每个阶段交付同步维护，不在本文堆积过时占位描述。

---

## 1. 全局壳层与通用不变量

| 维度 | 完成判据 |
|---|---|
| 认证守卫 | 未登录访问任意业务路由重定向至 `/login?next=<原路径>`（防开放重定向，仅允许单 `/` 开头）；会话被重置/改密/登出后，实时连接以 `4401` 断开且页面跳回 `/login`。 |
| 角色可见性 | 普通用户看不到左侧管理入口（`用户与邀请`、`存储`、`实时通道诊断`），直访 `/admin/*` 显示标题 `无权访问`；工作表结构与看板列配置对所有已登录用户开放（ADR-0003）。 |
| 导航实时性 | 左侧导航“工作表”分组实时列出未删工作表（色点 + 名称）；增删改工作表后无需刷新立即同步；无“归档”入口（ADR-0004）。 |
| 手机窄屏（390×844） | `document.documentElement.scrollWidth <= window.innerWidth`；顶部抽屉按钮 `打开导航` 可展开/收起导航；工作表允许表格容器内横向滚动，页面整体不错位。 |
| 零敏感泄漏 | 服务端 JSON 日志与实时事件 payload 均不含密码、`nw_session=`、邀请令牌、重置令牌（阶段 3 起亦不含提取码与签名 URL）。 |

## 2. 阶段 1 页面（已交付）

| 路由 | 核心用户流程 | 关键定位契约 | 完成判据 |
|---|---|---|---|
| `/reset/:token` | 初始管理员或被重置用户设置新密码 → 跳转 `/login?reset=1` | 标题 `设置新密码`、输入 `新密码` / `确认新密码`、按钮 `保存新密码` | 成功后提示 `密码已设置，请使用新密码登录`，旧会话全部失效 |
| `/login` | 输入登录名（大小写不敏感）与密码登录 → 进入首页 `/` | 输入 `登录名` / `密码`、按钮 `登录` | 账号不存在与密码错误提示完全一致；连续失败触发锁定 |
| `/invite/:token` | 凭一次性/限次邀请链接注册 → 自动登录进入首页 | 输入 `登录名` / `显示名` / `密码` / `确认密码`、按钮 `完成注册` | 支持中文、日文假名与全角字符；用完/作废/过期均提示 `邀请链接无效或已过期，请联系管理员` |
| `/settings` | 修改显示名、修改密码 | 输入 `显示名`、按钮 `保存显示名` | 修改显示名后提示 `显示名已更新` 并实时同步给他人；改密保留当前会话、踢掉其他设备 |
| `/admin/users` | 管理员生成邀请链接、调整用户角色、生成重置链接 | 按钮 `生成邀请链接` / `生成重置链接` / `确认生成` / `我已保存`、`data-testid="one-time-link-input"`、`#invRole` | 一次性链接仅展示一次；不能降级最后一位管理员；重置立即踢目标用户下线 |
| `/admin/realtime` | 管理员测试实时通道连通、断线模拟与补发 | 按钮 `发送测试事件` / `模拟断线` / `恢复连接`、`data-testid="diag-cursor"`、`data-testid="diag-event-log"` | 甲发事件乙 1 秒内可见；断线后恢复按序补齐且无重复 |

## 3. 阶段 2 页面（工作表、任务、看板与实时协同）

| 路由 | 核心用户流程 | 键盘 / IME / 交互契约 | 建议稳定定位与完成判据 |
|---|---|---|---|
| `/`（首页看板） | 查看顶部“我进行中的任务”条（一键标完成）、按工作表/作品/缺人/与我有关筛选、看板列一键竖向折叠、右上角「管理看板列」弹窗、点击作品聚合卡平滑展开/收起分段、点击 `+ 缺 <工序>` 认领、点任务打开详情侧栏 | 作品聚合卡默认折叠，点击展开内部各分段；认领期间按钮禁用防连点 | 初始 4 列（时轴/翻译/校对/嵌字）；并行进行中多列显示；同列内归属同一作品的分段聚合为 1 张作品折叠卡，无作品任务保持极简卡片；未开始落首个未完成上看板适用工序列；`na` 跳过；已发布或上看板适用工序全完成离开看板；认领只填负责人保持 `not_started` 且 1 秒内同步他人；并发抢认领后到者收 409 Toast |
| `/my-tasks` | 按“进行中 / 未开始”分组处理当前用户负责的工序，底部展开“我已完成” | 状态快捷切换即时同步，点击定位跳转 `/worksheets/:id?taskId=:taskId` | 仅包含当前用户账号负责的适用工序，绝不混入纯文本名字或 `na` |
| `/worksheets` | 新建工作表（名称/颜色/4 套模板）、拖动排序、改名改色、二次确认删表；项目级看板列增删改拖动排序（路由保留兼容；日常新建/改名/删表/拖序亦可在左侧导航栏原地完成） | 删工作表/删看板列均需确认弹窗 | 模板建表自动匹配同名看板列；删看板列后关联工序列自动置空（不上看板）且首页看板立即变化 |
| `/worksheets/:id` | 顶部视图标签栏切换「表格视图（Teable Canvas Grid）」与「看板视图（单表看板）」；跨整行可折叠「作品大标题横幅」（进度、改名、作品附件槽位、`+ 添加分段`）与无作品任务平铺；默认隐藏冗余「作品」列；顶部 `已发布（N 条）` 默认折叠条；新建/插入/拖动排序/软删（`sonner` Toast 一键撤销）；单元格内联编辑、工序格整格着色 + 附件角标槽位 + Popover、发布信息 Popover；表头 `+` 原地加列、列头菜单、字段显隐与列宽拖动落库；修改记录抽屉与一键恢复；在线用户头像条与 Canvas `collaborators` 焦点框；本地筛选与排序 | 文本格：单击选中（`editing: false`），双击或 `Enter` 编辑（`editing: true`），`Enter`/失焦提交，`Esc` 取消；支持方向键/`Tab` 跨格移动；**中文 IME**：`compositionstart` 至 `compositionend` 期间按 `Enter` 不提交、远端更新不覆盖草稿；启用筛选或非默认排序时禁用行拖动 | 同行改不同字段互不覆盖；同格并发冲突贴附 `[保留我的]` / `[采用对方的]` 冲突条且不丢草稿；所有工序完成但未发布**不折叠**，仅已发布折叠；他人关闭页面后头像与焦点框自动消失；断线补发与超限 `resync` 后数据一致；带 `?taskId=` 跳转自动展开（若已发布或所在作品已折叠）、滚动高亮并打开侧栏 |
| 任务详情侧栏（共用） | 桌面端右侧 440px 滑出、手机端全屏抽屉；归属作品的任务顶部预留所属作品共用附件区；编辑字段/工序、查看本任务修改记录、点“在工作表中定位”跳转 | `Esc` 关闭侧栏（非输入法组字且无内层弹层时） | 文件区与作品共用附件区保留阶段 3 占位提示；任意页面修改后其他页面实时同步 |
| `/search` | 跨所有工作表中文子串检索（300ms 防抖），支持工作表/状态/隐藏已发布筛选 | 点击结果项直达 `/worksheets/:worksheetId?taskId=:taskId` | 命中标题、作品名、分工说明、负责人显示名/纯文本名字、工序备注、自定义文本列；软删表与任务不泄漏 |

## 4. 后续阶段预留契约（差分测试与专项验证）

- **阶段 3–4（文件与 R2 上传）**：新增四级统一文件挂载（作品大标题共用附件、任务级文件、工序格内一键下载最新附件角标、项目参考资料）、文件侧栏、多入口、分片续传与版本历史验证；删除工序列自动降级附件与删除作品保护验证；提取码与签名 URL 纳入日志与实时事件零泄漏属性扫描；上传完成接口纳入幂等与并发版本属性测试。
- **阶段 5（旧资料导入 — 差分测试 Oracle）**：以字幕组 23 张历史 Excel 工作表的小样 + 人工确认映射作为 Oracle，将“导入 → 系统结构化导出”与 Oracle 逐行差分比对，维护显式归一化白名单（全角空白/NFC 等）；同批数据重复导入 2 次数据库状态零漂移。
- **阶段 6（运维与备份恢复）**：备份恢复前后执行全库关键实体（工作表、任务、工序格、版本、入口）差分快照一致性校验。
