# 只设管理员与普通用户两个角色

设计文档 v1.8 以前有管理员、统筹、成员三个角色，统筹独有“建表、配置工序列与看板列、导入导出”的权限。阶段 1 开工前用户决定只保留管理员（`admin`）和普通用户（`user`）：统筹的权限全部并入管理员，管理员可以有多个，负责统筹的人直接设为管理员。理由是小组自用，权限判断越简单越好；代价是做统筹的人同时拥有用户管理和存储清理的权限。

## 考虑过的方案

- 保留三个角色：权限最细，但多一层要解释和维护的判断。
- 建表与配置列开放给所有用户，只把导入导出留给管理员：更接近共享表格的习惯，但结构被误改的影响面大。

## 后果

权限判断只有“是否管理员”一个分支。若将来需要中间角色，应新增角色并在权限表里给它一列，而不是给个别用户开特例。
