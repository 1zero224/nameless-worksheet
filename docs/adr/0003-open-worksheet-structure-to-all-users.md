# 工作表与看板列的结构配置对所有用户开放

[ADR-0001](0001-two-roles-no-coordinator.md) 曾把建表、配置列与看板列（`worksheets.manage`）划归管理员专属。阶段 2 设计时用户决定取消这层限制：所有已登录用户都可以新建/编辑/排序/删除工作表、增删改列、调整列宽与列显隐、配置看板列，改动直接落库并实时同步给所有人；只有临时筛选与排序留在当前浏览器页面。管理员专属权限收缩为用户与邀请、导入导出、存储管理与实时诊断。

## 考虑过的方案

- 拆分为“管理员管结构 + 个人本地存列宽与显隐”两层：保护表结构不被误改，但与小组共享表格的自由协作习惯不符，也增加了双层状态的解释成本。
- 仅开放单表内列配置，建表与看板列仍限管理员：多一层权限边界，对小组日常使用意义不大。

## 后果

- `packages/shared/src/permissions.ts` 中的 `worksheets.manage` 调整为 `admin` 与 `user` 均允许（保留权限键以便将来按需收回，且不破坏阶段 1 的路由权限检查机制）。
- 误改或误删工作表、列的风险由“删除前二次确认 + 软删除 + 工作表修改记录”兜底，而不是靠角色拦截。
